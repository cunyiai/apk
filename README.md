# 🩺村医AI-离线多模态ai助手 

**Android离线多模态助手**

- 基于 MNN Chat APK 二次开发，仅保留简体中文界面
- 内置 Qwen3-VL-2B-Thinking-MNN 模型配置
- 村医问诊 System Prompt（症状分析、用药指导、就医建议）
- 首次运行仅需下载所需模型
- 👀让ai识别图片的小提示技巧: 看到什么

## 💊功能特性

- 离线多模态AI助手（基于MNN引擎）
- 首次运行仅需下载 Qwen3-VL-2B-Thinking-MNN 模型
- 支持图像识别、语音对话等


## 🔧安装说明

1. 下载 APK 文件到手机
2. 允许安装未知来源应用（设置→安全→未知来源）
3. 安装后首次运行要下载所需AI模型

### 系统要求

- Android 8.0+ (API 26+)
- 4GB+ 运行内存
- 约 3GB 存储空间（模型）

## 💻 开发指南

### 环境要求

- Android Studio Hedgehog (2023.1.1)+
- Java 17 JDK
- Android SDK API 34
- Gradle 8.5
